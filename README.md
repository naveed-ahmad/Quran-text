# Quran Text in IndoPak Script (Deprecated)

This repository contains an **experimental attempt** at preparing the **IndoPak word-by-word Quran script**, that we can render with the **PDMS Saleem** font.

This work served as an initial prototype and is **no longer maintained**.

---

## 🚫 Deprecation Notice
